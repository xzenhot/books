Lipika Lite !

An Indian input system for typing using englsh keyboard.

The keyboard is based on window native api and integrated with keyboard hooks. Lipika lite is provided as is , with free acces and usage. No fees are required for this version.

For more information about usage and licences , please refer the website: https://lipika.xzen.in and read it properly.

For typing in Bengali Language, there are more appropriate models which suits your requirement. In a general sense, if you are more into language like news paper, you should follow 'ananda' model. If you are looking for research paper kind of work, then you can follow 'wiki' model. For general purpose always follow basic 'default' model.

For more specific needs, you can find and download load models from Keyboard website. People who write poetry, they can follow 'baak' or 'dehlij' model. You have to download them and place these model files in proper directoy.
